# 🚀 Portfolio 

Bienvenido/a a mi portfolio.
En este repositorio se presentan algunos de mis proyectos principales, desarrollados con foco en la **calidad del software, buenas prácticas y escalabilidad**.

## 💻 Sobre los proyectos

Los proyectos incluidos aquí han sido **adaptados (mockeados)** con el objetivo de poder ser desplegados como demos funcionales, permitiendo visualizar su comportamiento en un entorno accesible.

🔎 A tener en cuenta:

* Cada proyecto mantiene su **lógica, estructura y enfoque original**.
* El **código completo** se encuentra en sus respectivos repositorios individuales


## ⚙️ Tecnologías y herramientas

En estos proyectos utilizo:

* JavaScript / React
* C# / .NET
* Python / Node.js
* Playwright / Typescript
* Desarrollo frontend/backend (según proyecto)
* Consumo y testing básico de APIs
* Manejo de entornos y configuración
* Buenas prácticas de código y estructura

## 🧠 Enfoque de trabajo

Si bien mi perfil es principalmente de desarrollo, trabajo con una fuerte **orientación a QA**, lo que implica:

* Pensar en casos de uso y posibles escenarios desde el inicio
* Escribir código mantenible y testeable
* Validar funcionalidades de forma estructurada
* Tener en cuenta la experiencia del usuario y posibles fallos

## 📊 Qué vas a encontrar

* Proyectos funcionales desplegados como demo
* Código organizado y legible
* Enfoque en calidad y estructura
* Bases preparadas para futura automatización de pruebas

## 🎯 Objetivo

Este portfolio tiene como objetivo mostrar mi capacidad para desarrollar soluciones funcionales, con una base sólida orientada a la calidad, y en constante evolución hacia prácticas más avanzadas de testing y automatización.
